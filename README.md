# Compilateur-du-C

Implémentation en Python d'un compilateur pour un sous-ensemble du langage C, développé dans le cadre de mes études à Polytech Paris-Saclay.

## Contenu

- **Lexer** : analyse lexicale du code source C, découpage en tokens (mots-clés, identifiants, constantes, opérateurs...)
- À venir : parseur (analyse syntaxique), génération de code
